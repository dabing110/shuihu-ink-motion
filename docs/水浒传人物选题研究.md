## 二、缺口诊断

1. **前两条线已封顶。** 逼上梁山与梁山核心各 5 部，同类人物再补边际收益低，不必再做王伦、刘唐、朱仝这类。
2. **女性是最大的结构性空白。** 16 部全男，扈三娘是全书最锋利的一笔：全家被李逵杀尽，却由宋江作主嫁给了王英。视频号上差异化题材最容易出圈。
3. **五虎将只做了关胜。** 秦明是其中最有戏的——宋江设计害死他全家再逼他入伙，是「梁山黑」的明证，也是招安逻辑的黑暗预演。
4. **全身而退者谱系差两人才闭合。** 招安覆灭这个主题全靠这条线收口：公孙胜修道、燕青归隐已做，柴进辞官、李俊出海为王还没做。李俊与阮小七的对照是全书最好的一组——一个出海为王，一个回村打鱼。

## 六、制作约定速查

- **规格**：1920×1080 @60fps，配音 + 烧录字幕双门禁，语速 ≤+30%
- **时长（2026-10-28 变更）**：不再死守 8 幕 24.80s。人物故事性优先，可延长到 **26–32s**（增加幕数到 9–10 幕，或加长单幕），**上限 35s**。旧片仍是 3.0/2.8/3.0/3.0/3.2/3.0/3.0/3.8 = 24.80s 的八幕制，新片按需突破
- **排期（2026-10-28 定）**：23:05 起依次做 第一梯队 SH-22~25 → 第二梯队 SH-26~29 → SH-30 高俅，共 9 部
- **朱砂铁律**：全片仅朱砂一味 `rgba(183,51,46,.xx)`，只用于钤印 / 特定血光 / 特定器物点缀，其余纯黑白灰
- **转场**：可用 dotBloom / smash / radiant / whip / goldLeaf / redWedge / ripple；**禁用 chiaroscuro（全黑+暖光）与 dabs（彩色光斑）**
- **活气 QA**：不能用平均帧差（版画大片留白 + 慢动作会误报），必须用「相邻帧灰度差 >8 的像素占比」——幕内 <0.10% 记死帧嫌疑，>32% 记跳变嫌疑，转场豁免窗口 `b-0.6 <= t <= b+0.7`
- **渲染**：`render_chunked.sh <film> <绝对OUT路径>`，**短片 3×496 帧（24.8s）约 14 分钟/部；长片 5×403 帧（33.6s）约 20–25 分钟/部**；**OUT 必须传绝对路径**
- **rig 命名**：拼音文件名（如 `chaogai.js` 不用中文），`Z.<名>` 本体 + 小件，末尾 `SCENES['<id>']` 注册
- **已踩过的坑**：
  1. 手持兵器/乐器必须画在人物变换的 `c.restore()` **之前**，否则画到屏幕坐标外（燕青箫、李逵斧、花荣弓都中过招）
  2. 人物 signature 纹样**优先用文字徽记**（如卢俊义胸前「麒麟」二字），复杂兽形在 1100px 复核时必糊成一团
  3. 写既有配置文件前先写 `.tmp` 再 `os.replace`——沙箱会拦截对已存在文件的直接 `open('w')`
  4. 跨片复用他人 rig 时，要把该角色 js 加进自身 `SCENE_LIBS`
  5. `eras` 的 `durs` 之和**必须等于** `lines` 的 `total`（转场时长已嵌入每幕 dur，不额外叠加）；否则字幕与成片错位
  6. 结句白底标题框的**填充色不可与宣纸 `#e8e6de` 同色**（否则框不可见，只看见文字浮在纸上），须加一道深色细边框（如 `rgba(26,26,28,.5)`）才成「带框标题条」；且淡入窗口应早现长持（`ss(0.5,1.6)`），别拖到末 1 秒才显
  7. **`Z.manor` / `Z.shanzhai` 的 y 是「底部」**（墙体/栅栏从 y=0 往上长），必须贴地面线（与人物脚同高，通常 892）；设在 620~730 会让整座建筑/招牌悬空 170~270px。但**贴地后要复查是否压住中央人物**——山寨宽约 ±240，与中央立像同 x 会重叠，此时应把建筑移到侧后方（如 x=1430、s=0.74）而非缩小居中
  8. **深色墨线画在深色暗块上等于没画**——「蒸笼白气 / 蒸汽 / 雾」这类意象必须用**纸白线**（`col` 传近 `[252,251,246]`）画在焦墨灰块（`rgba(26,26,28,.5)` 填充）上才显；反过来，白线画在浅色宣纸底上也看不见
  9. **组合道具必须补连接件，且线要够粗**——扁担 + 两只筐之间若不画垂绳，1100px 复核会读成「横杆 + 两个孤立方块」；绳子线宽 ≥3.4、tone ≥0.9（2.2/0.72 在降采样后直接消失）。同理，小道具（木枷）别小于 60×30px，否则只剩一根横线认不出
